# Plutonium Network

**Building an open, accessible ecosystem of software, games, and web technologies.**

Plutonium Network is an independent software organization focused on building **useful, accessible, and self-hostable technology** across the web and desktop.

What started as a platform for browser-based games has grown into a collection of projects spanning **web applications, game infrastructure, networking, cloud technologies, developer tools, and standalone software.**

Our goal is simple:

> **Build software that people can actually use, regardless of where they are or what platform they're on.**

---

## What We Build

Plutonium Network develops and maintains projects across several areas.

### Games & Entertainment

We maintain infrastructure for browser-playable games and other interactive experiences.

Our game ecosystem includes:

* Browser-playable games
* Game hosting infrastructure
* Game distribution systems
* Cloud gaming experiments
* Game APIs and supporting services

We aim to make games accessible directly from the browser without requiring users to install complicated software.

---

### Web Technologies

We build web applications and infrastructure designed to work efficiently in restricted or unconventional environments.

Our projects explore areas such as:

* Web proxies
* Content delivery
* API infrastructure
* Web applications
* Browser-based utilities
* Networking technologies

---

### Standalone Software

Plutonium isn't limited to websites.

We also build software that runs directly on the user's machine, including Windows utilities and standalone applications.

Projects such as **CustomNew** aim to improve everyday workflows by adding functionality that isn't provided by the operating system itself.

---

### Experimental Technology

Some of our projects exist specifically to explore what's possible.

We're actively experimenting with:

* Standalone browsers
* Virtual machines in the browser
* Cloud gaming
* AI integrations
* Media platforms
* Encrypted communication
* File transfer systems
* New web infrastructure

Not every experiment becomes a finished product.

That's part of the point.

**We build, test, break, improve, and build again.**

## Our Philosophy

### Accessibility

Software should be accessible to as many people as possible.

We try to avoid unnecessary barriers between users and the software they want to use.

### Independence

Whenever practical, we build our own infrastructure instead of depending entirely on third-party platforms.

### Experimentation

We aren't afraid to try unconventional ideas.

Some of our projects are experimental by design.

### Open Development

Our public repositories allow anyone to inspect the code, contribute improvements, report issues, or build their own versions.

## Development Status

Plutonium Network is **actively developed**.

Some projects are production-ready, while others are experimental or still under heavy development.

Expect things to change.
